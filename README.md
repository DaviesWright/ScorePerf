# ScoReviewHR

ScoReviewHR is a people-performance and talent development platform from Senrab Technologies. It aligns employee goals, continuous performance management, development and talent decisions with business objectives.

The product lives in [`hr-platform/`](hr-platform/): a Hono API on Cloudflare Workers, a Next.js frontend and a Neon PostgreSQL database. See [`hr-platform/README.md`](hr-platform/README.md) to run it, [`ScoReviewHR Roadmap.md`](ScoReviewHR%20Roadmap.md) for what is built and what is planned, and [`docs/`](docs/) for architecture decisions.

## History

Until 30 November 2026 this repository also held a Django application based on the open-source Horilla HR project. It was frozen on 21 November 2026 and removed after that (roadmap decision D-06). It remains in git history; the last commit that contains it is the parent of the removal commit.

## Security

See [SECURITY.md](SECURITY.md). ScoReviewHR is not SOC 2 or ISO 27001 certified.
